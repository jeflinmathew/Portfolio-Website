### 🖼️ Full-Site Lightbox Gallery
- Click any image across the portfolio to open a full-screen lightbox viewer.
- **← →** arrow buttons + keyboard `ArrowLeft` / `ArrowRight` to cycle through **all images site-wide** in a continuous loop.
- **Touch swipe** support for mobile users.
- **▶ Auto-scroll / Slideshow** button — automatically advances to the next image every 3 seconds.
- **⬇ Download** button — downloads the currently viewed image directly.

### 📱 Mobile UI — Chatbot Only
- On mobile screens (≤ 860px), the inline hero chat widget is hidden.
- Only the circular **Chat FAB** (floating action button) is shown — tap it to open the full-screen AI chatbot overlay.

### 💬 AI Chatbot — Icon-Only FAB
- The floating chat button now shows only the chat icon inside a clean round button — no text label.

### 🎨 Clean Visual Design
- **No dividing lines** between sections — seamless scrolling experience.
- **Solid backgrounds** in both dark (`#0B0B0B`) and light (`#FFFFFF`) modes — no radial gradients or glow overlays.
- Hover color effects on interactive elements throughout the site.

```

├── index.html        # Single-page app — all UI, logic, and AI chatbot
```

## 🚀 Running Locally

```bash
# Clone the repository
git clone https://github.com/jeflinmathew/Portfolio-Website.git
cd Portfolio-Website

# Start the local server on port 8080
node server.cjs
```

Then open **http://localhost:8080** in your browser.
